Excel HR Analytics Dashboard

Project Overview

This project is an HR Analytics Dashboard created using Microsoft Excel to analyze employee data, employee attrition, and workforce insights.

Objectives

- Analyze employee data.
- Understand employee attrition.
- Identify workforce trends.
- Present HR information through an interactive dashboard.

Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Excel Formulas

Project Description

This dashboard helps analyze HR data and present important workforce information in a visual format. It helps users understand employee trends and make better HR decisions.
